Weights and bias, forward and backward propagation

Every neuron adds up its inputs multiplied by weights, plus a bias, and passes the sum through an activation function such as the sigmoid. Forward propagation runs this up to the prediction, the loss measures how wrong the prediction is, and backpropagation lowers the loss by moving each weight with \(w_{\text{new}} = w_{\text{old}} - \eta\,\partial L/\partial w_{\text{old}}\).

At a glance

  • Two steps happen inside every neuron. Step 1 is the weighted sum plus a bias, \(z = \sum_i x_i w_i + b = \mathbf{w}^\top\mathbf{x} + b\), the same form as linear regression. Step 2 is an activation function. The sigmoid \(\sigma(z) = 1/(1 + e^{-z})\) gives a value between 0 and 1, read as class 1 when it is at least 0.5. A regression output uses a linear activation.
  • Weights decide how strongly each input activates a neuron, like the nerves that make only the hand holding something hot pull away. The bias is a constant, the counterpart of an intercept, added in every layer. Krish motivates it with weights that start at 0.
  • Forward propagation runs inputs × weights + bias → activation, layer by layer, up to the prediction \(\hat y\). The loss measures the gap to the truth. The first student in the data passed (\(y = 1\)) but is predicted 0, so \(y - \hat y = 1\).
  • Backpropagation lowers the loss by updating every weight with an optimizer such as gradient descent, \(w_{\text{new}} = w_{\text{old}} - \eta\,\partial L/\partial w_{\text{old}}\). A negative slope makes the weight grow and a positive slope makes it shrink, so either way it moves toward the global minimum.
  • The learning rate \(\eta\) should be small, such as 0.001 or 0.01, so that the weights converge. A large one jumps around the minimum. Training repeats forward and backward passes many times, and a multi-layer network runs the same steps in every layer. The chain rule that computes \(\partial L/\partial w\) is the subject of Part 3.

What happens inside a neuron

Part 1 (krish-dl-01.html) ended with the layers of a network: an input layer, an output layer and, between them, any number of hidden layers. Each hidden layer can have its own number of neurons, for example five to ten in the first and a hundred in the next, and the signal passes from neuron to neuron. This part asks what a neuron does with the signal it receives, and what the lines between neurons are for.

The example is the student data set from Part 1. For each student it records hours of study, play and sleep, and whether the student passed (1) or failed (0). The first record is study 7, play 3, sleep 7, passed. Its three values enter the input layer as \(x_1, x_2, x_3\), one record at a time. Krish first draws two neurons in the hidden layer and stresses that every input is connected to every neuron, the way brain cells pass signals on 32:56. Each connection carries a weight. To keep the drawing readable he then reduces the hidden layer to one large neuron, with room for the two operations that happen inside it, followed by one output neuron.

Step 1 is the weighted sum. Multiply each input by the weight on its connection and add the products 34:34:

\[ \sum_{i=1}^{3} x_i w_i = x_1 w_1 + x_2 w_2 + x_3 w_3 = \mathbf{w}^\top\mathbf{x} \]

This has the same form as linear regression, written as \(\beta_0 + \beta_1 x\), as \(\boldsymbol\beta^\top\mathbf{x}\) or as \(y = mx + c\) 35:36. A bias \(b\) is added to it shortly and plays the part of the intercept. Step 2 passes the result to an activation function. Before step 2, Krish explains what the weights and the bias are for.

Notation. In the video the weighted sum is called \(y\) on day 1, and on day 2 the activated value is called \(z\). These notes keep \(y\) for the true label, write \(z\) for the weighted sum, and write \(O_1\) for the hidden neuron's output, as Krish does on day 1.

What the weights do

Krish's analogy: if someone puts a hot object in your right hand, you pull the right hand away and leave the left hand where it is. The neurons on the path from the right hand pass the signal to the brain and get activated, and the ones for the left hand do not. In a network the weights play this role. They decide whether a neuron is activated, and to what level.

In his words, a weight says "how much the neuron should get activated or deactivated". Training a network means finding the value of each weight that makes the right neurons fire to the right degree. He offers this as the simplest way to understand weights, and the explanation he would give in a job interview.

Why a bias is added

Suppose the weights start at 0, which is one possible starting point among several. Then \(x_1 \cdot 0\), \(x_2 \cdot 0\) and \(x_3 \cdot 0\) are all 0, and the neuron passes on nothing but 0. To avoid that, a second kind of parameter is added, the bias \(b\). It is a constant, the counterpart of the intercept \(c\) in \(y = mx + c\). Even if every weight was initialized to 0, the bias keeps the value away from 0, so training can carry on and the weights can be updated later.

Answering a viewer's question, he adds that a bias is needed in every hidden layer. Step 1 therefore becomes

Step 1 with the bias \[ z = \sum_{i=1}^{n} x_i w_i + b = \mathbf{w}^\top\mathbf{x} + b \]

Not in the video: the usual reasons. A bias lets a neuron shift the point where it switches on. Without it the weighted sum is 0 whenever every input is 0, just as a line without an intercept must pass through the origin. A weighted sum of 0 does not stop the signal either, since the sigmoid turns it into 0.5. Starting every weight at 0 has a different problem. The neurons of a hidden layer then start identical, receive identical updates and stay identical, and a bias does not change that. This is why weights start at small random values, as Krish says on day 2. Lecture 7 (lecture-07.html) covers it.

Step 2: the activation function

The weighted sum \(z\) goes into an activation function, which decides whether the neuron is activated or not, like the hand that moves or stays still. Krish's first example is the sigmoid activation function, used for binary classification. ReLU and the other activation functions come later, in Part 4 (krish-dl-04.html).

Sigmoid activation \[ \sigma(z) = \frac{1}{1 + e^{-z}}, \qquad z = \sum_i x_i w_i + b \]

The sigmoid's output lies between 0 and 1. (Krish first says it outputs 0 or 1, then corrects himself.) To get a class, a threshold is applied 41:36:

\[ \text{class} = \begin{cases} 1 & \text{if } \sigma(z) \ge 0.5 \\ 0 & \text{if } \sigma(z) < 0.5 \end{cases} \]

The two steps happen in every neuron. The hidden neuron's output \(O_1 = \sigma(z)\) travels to the output neuron along a new weight \(w_4\). There the same two steps run again, a weighted sum and an activation, and the network's final output is 0 or 1. For binary classification the output neuron uses the sigmoid. For regression it uses a linear activation function, which leaves the weighted sum as it is.

At this point Krish lists the terms met so far: neurons, weights, bias, hidden layers and activation functions.

Forward propagation

Everything done so far, from the inputs to the output, has a name. Take the inputs, multiply them by the weights, add a bias and activate, layer after layer until the output is reached. This whole pass is forward propagation. For the small network of the figure above it is four lines:

  1. Forward propagation, 3 inputs, 1 hidden neuron, 1 output neuron
  2. \(z_1 = w_1 x_1 + w_2 x_2 + w_3 x_3 + b_1\), the weighted sum plus bias in the hidden neuron.
  3. \(O_1 = \sigma(z_1)\), its activation.
  4. \(z_2 = w_4 O_1 + b_2\), the weighted sum in the output neuron.
  5. \(\hat y = \sigma(z_2)\), read as class 1 if \(\hat y \ge 0.5\) and class 0 otherwise.

On day 1 Krish puts a bias in the hidden layer only. For the multi-layer network he says a bias is added in every layer, so the output bias \(b_2\) is included here.

44:48 45:57 y − ŷ 47:00 the loss function

Prediction, truth and the loss

Pass the first record, \((7, 3, 7)\), forward, and suppose the network outputs 0. That output is the predicted value \(\hat y\). The true value \(y\) for this student is 1, since the student passed. The difference is

\[ y - \hat y = 1 - 0 = 1 \]

The output is completely wrong. The aim is to bring this difference very close to 0, because only then does \(\hat y\) match \(y\). The quantity that measures the difference between the predicted and the real value is the loss function. There are several kinds, covered in Part 4, and the goal with every one of them is to minimize it.

Not in the video: as a training target a plain difference is not enough, because it can be negative. For a student who failed (\(y = 0\)) and a prediction \(\hat y = 1\), \(y - \hat y = -1\), and making that number smaller would push \(\hat y\) further up. Losses therefore measure the size of the error, for example the squared error \((y - \hat y)^2\), which Krish mentions on day 2 for linear regression. The widget at the end of this page uses it.

Backpropagation and optimizers

When the loss is large, the network runs backpropagation (backward propagation). Its main aim is to update the weights, since only by changing the weights can the predicted output come to match the real one. The problem is supervised, so the real output is known. Here it should be 1, and the network says 0.

The updating is done by an optimizer, which makes sure each weight is updated while the error is propagated back. Krish asks viewers not to worry yet about the maths inside it and to focus on the training process. That process involves the weights and the bias, the two operations inside each neuron, forward propagation to the output, the loss, and, if the loss is high, a backward pass in which an optimizer updates the weights.

The familiar example of an optimizer is gradient descent in simple linear regression 50:49. There the cost plotted against a coefficient is a U-shaped curve. Gradient descent changes the coefficient step by step until it reaches the global minimum, the point where the difference between \(y\) and \(\hat y\) is smallest. The same happens to the weights of a neural network. Gradient descent is one kind of optimizer, and Part 5 (krish-dl-05.html) covers the others.

For the IIT Madras treatment of gradient descent, see Lecture 3 (lecture-03.html), and of optimizers, Lecture 5 (lecture-05.html).

The training loop in five steps

Krish sums up the first session as a story in five steps.

  1. Training a neural network
  2. Input layer. A record enters the network.
  3. Weights. Each connection multiplies its input by a weight.
  4. Sum and bias. Each neuron adds up the weighted inputs together with its bias.
  5. Activation. An activation function is applied. Steps 2 to 4 repeat until the last layer. Together they are forward propagation.
  6. Backward propagation. First the loss is computed, the difference between \(y\) and \(\hat y\). An optimizer then updates the weights to minimize it.

One forward pass and one backward pass, repeated many times (he says a thousand, for instance), train the network, much as a baby learns a word by hearing it day after day. Every model in deep learning trains this way, whether it is an ANN, a CNN, an RNN or an object detector; what changes is the optimizer. Sometimes ten rounds are already enough 54:00.

His second illustration: show someone a flower they have never seen and tell them it is a black rose. The next day they may not remember the name. After seeing it again on the second, third and fourth day, they name it confidently themselves. A network is trained the same way, by seeing the data again and again.

Multi-layer neural networks

The network drawn so far, with one hidden layer, is what Krish calls a single-layer neural network. A multi-layer neural network has many inputs, several hidden layers with any number of neurons each, and an output layer that can have several neurons, for example one per class in multi-class classification. Every neuron is connected to every neuron of the next layer.

It works exactly like the single-layer network. In every layer the neurons compute a weighted sum, add a bias and apply an activation, and training is still forward and backward propagation. For multi-class problems a different activation function and a different loss function may be used, and that is the only difference. Nor is the network limited to two hidden layers; it can have any number.

The weight update formula

To reduce the loss the weights must change, and that happens in backpropagation. Krish splits backpropagation into two parts, the weight update formula and the chain rule of differentiation. In the small network the backward pass has to update \(w_4\), \(w_1\), \(w_2\) and \(w_3\). The generic formula, and the place where optimizers come in, is

Weight update formula \[ w_{\text{new}} = w_{\text{old}} - \eta\,\frac{\partial L}{\partial w_{\text{old}}} \]
  • \(w_{\text{old}}\) is the weight's current value, the one used in the forward pass.
  • \(\eta\) is the learning rate, a small positive number discussed below.
  • \(\partial L/\partial w_{\text{old}}\) is the derivative of the loss with respect to that weight. It is the slope of the loss at the current weight.

Linear regression updates its coefficients in the same way. For the IIT Madras derivation of this rule from a Taylor series, see Lecture 3 (lecture-03.html).

Not in the video: biases are updated by the same rule, \(b_{\text{new}} = b_{\text{old}} - \eta\,\partial L/\partial b_{\text{old}}\).

Why the formula moves the weight the right way

Plot the loss against one weight and you get a U-shaped curve, the same picture as in linear regression. Krish calls it the gradient descent curve. Its lowest point is the global minimum, and training must bring the weight there. The curve is drawn in two dimensions, but with many weights it is a surface, like a mountain turned upside down, and the aim is still to reach its lowest point 1:09:59.

To find the slope at the current weight, draw the tangent to the curve there. Calculation gives the sign of the slope directly, but there is a quick visual check. If the right-hand end of the tangent points down, the slope is negative. If it points up, the slope is positive.

  • Negative slope (left of the minimum, point A in the figure). To reach the minimum the weight must increase. The formula gives \(w_{\text{new}} = w_{\text{old}} - \eta \cdot (\text{negative})\), which is \(w_{\text{old}}\) plus a positive amount, so \(w_{\text{new}} > w_{\text{old}}\) and the weight does increase.
  • Positive slope (right of the minimum, point B). The weight must decrease, and \(w_{\text{new}} = w_{\text{old}} - \eta \cdot (\text{positive}) < w_{\text{old}}\).

On either side the minus sign turns the slope into a step toward the minimum. That is gradient descent. In linear regression the curve comes from the loss \((y - \hat y)^2\) plotted against the weights 1:14:57.

Strictly, the curve is the loss curve, and gradient descent is the procedure that walks down it. Krish uses the name for both.

The learning rate

The learning rate \(\eta\) sets the size of each step toward the global minimum. The weight can take large steps or small ones, and Krish's advice is to keep the learning rate small. With a small learning rate the weight converges slowly and steadily to the global minimum. With a large one the weight jumps here and there and may never reach the minimum at all.

The values he usually takes, and in his words most researchers too, are 0.001 or 0.01. He promises to show the effect in the practical session (Part 6, krish-dl-06.html). The widget below shows it on a made-up loss curve.

For the IIT Madras treatment of choosing and annealing the learning rate, see Lecture 5 (lecture-05.html).

Where the slope comes from, and one full step

With the update formula in place, Krish turns to the second part of backpropagation, the chain rule of differentiation. The formula needs \(\partial L/\partial w_{4,\text{old}}\), and \(w_4\) affects the loss only through the output neuron. The chain rule computes such a derivative one link at a time. The chapter ends just as he starts on \(w_4\), and Part 3 (krish-dl-03.html) works it out.

Not in the video (a preview of Part 3): for this network with sigmoid neurons and the squared error \(L = (y - \hat y)^2\), the chain rule gives the slopes below. The second one multiplies two more links, through \(O_1\) and the hidden neuron's sigmoid.

\[ \frac{\partial L}{\partial w_4} = \underbrace{-2(y - \hat y)}_{\partial L/\partial \hat y}\;\underbrace{\hat y(1 - \hat y)}_{\partial \hat y/\partial z_2}\;\underbrace{O_1}_{\partial z_2/\partial w_4}, \qquad \frac{\partial L}{\partial w_1} = -2(y - \hat y)\,\hat y(1 - \hat y)\, w_4\, O_1(1 - O_1)\, x_1 \]

The widget runs one forward pass and one update on Krish's small network with live numbers. The records are the three students of Part 1's data set, and the starting weights are made up. With them the first student, who passed, gets \(\hat y = 0.399\), which is class 0, the same kind of wrong answer as in Krish's example. For \(w_4\) the slope is \(-2(0.601)(0.240)(0.378) = -0.109\). With \(\eta = 1\) the update gives \(w_4 = 0.5 + 0.109 = 0.609\), and the loss falls from 0.362 to 0.350. Choose another weight or record, read its slope, and apply the formula.

Key terms

Neuron (two steps)
Computes the weighted sum \(z = \sum_i x_i w_i + b = \mathbf{w}^\top\mathbf{x} + b\), then applies an activation function to it.
Weight
The number on a connection that multiplies an input. It decides how strongly that input activates the next neuron, and it is learned in training.
Bias \(b\)
A constant added to the weighted sum, like the intercept of a line. Every hidden and output neuron has one.
Activation function
Applied to \(z\). It decides whether, and how strongly, the neuron is activated, and it makes the network non-linear.
Sigmoid
\(\sigma(z) = 1/(1 + e^{-z})\), with output between 0 and 1, read as class 1 if it is at least 0.5. Used for binary classification.
Linear activation
Leaves \(z\) unchanged. Used in the output layer for regression.
Forward propagation
Inputs times weights, plus bias, then activation, layer by layer up to the prediction \(\hat y\).
Loss function
Measures the difference between the prediction \(\hat y\) and the true value \(y\). Training minimizes it.
Backpropagation
The backward pass that updates every weight so as to reduce the loss.
Optimizer
The method that updates the weights during backpropagation. Gradient descent is one example.
Weight update formula
\(w_{\text{new}} = w_{\text{old}} - \eta\,\partial L/\partial w_{\text{old}}\), where \(\partial L/\partial w_{\text{old}}\) is the slope of the loss at the current weight.
Learning rate \(\eta\)
The step size of the update. Small values such as 0.001 or 0.01 converge slowly but surely; large ones can jump past the minimum.
Global minimum
The lowest point of the loss curve, where the slope is 0. Training moves the weights toward it.
Multi-layer neural network
A network with several hidden layers, every neuron connected to every neuron in the next layer.

Test yourself

Q1Run the forward pass for the first student, \(\mathbf{x} = (7, 3, 7)\), with \(w_1 = 0.2\), \(w_2 = -0.4\), \(w_3 = -0.1\), \(b_1 = 0\), \(w_4 = 0.5\) and \(b_2 = -0.6\). Which class does the network predict, and is it right?

Hidden neuron: \(z_1 = 0.2 \cdot 7 - 0.4 \cdot 3 - 0.1 \cdot 7 + 0\), that is \(1.4 - 1.2 - 0.7 = -0.5\), so \(O_1 = \sigma(-0.5) = 0.378\). Output neuron: \(z_2 = 0.5 \cdot 0.378 - 0.6 = -0.411\), so \(\hat y = \sigma(-0.411) = 0.399\). This is below 0.5, so the predicted class is 0. The student passed (\(y = 1\)), so the prediction is wrong, and the squared error is \((1 - 0.399)^2 = 0.362\).

Q2A weight has \(w_{\text{old}} = 0.5\) and the slope there is \(\partial L/\partial w = -0.8\). With \(\eta = 0.01\), what is \(w_{\text{new}}\)? Repeat for a slope of \(+2.4\) at \(w_{\text{old}} = 1.2\) with \(\eta = 0.001\).

\(w_{\text{new}} = 0.5 - 0.01 \times (-0.8)\), which is \(0.5 + 0.008 = 0.508\). The slope is negative, so the weight increases. In the second case \(w_{\text{new}} = 1.2 - 0.001 \times 2.4\), which is \(1.2 - 0.0024 = 1.1976\). The slope is positive, so the weight decreases. Both steps move toward the minimum, and both are small because \(\eta\) is small.

Q3Why does a neuron have a bias? Give Krish's reason and the usual one.

Krish's reason: if all weights start at 0, every product \(x_i w_i\) is 0 and the neuron passes on 0. The bias, a constant like the intercept \(c\) in \(y = mx + c\), keeps the value away from 0 so training can continue. The usual reason: the bias shifts the point where the neuron switches on. Without it the weighted sum must be 0 whenever all inputs are 0, just as a line without an intercept must pass through the origin. Zero initialization is avoided for a separate reason: identical neurons get identical updates and stay identical.

Q4The first record gives \(\hat y = 0\) while \(y = 1\). What is \(y - \hat y\)? Why is a plain difference a poor quantity to minimize, and what is used instead?

\(y - \hat y = 1 - 0 = 1\), so the prediction is completely wrong and training should bring the difference close to 0. A plain difference can be negative: for \(y = 0\) and \(\hat y = 1\) it is \(-1\), and making it smaller would push \(\hat y\) further from the truth. A loss measures the size of the error instead, for example the squared error \((y - \hat y)^2\). Here it equals 1, and it is 0 only when \(\hat y = y\).

Q5A loss is \(L(w) = (w - 3)^2\), so \(dL/dw = 2(w - 3)\). Start at \(w = 1\). What happens with \(\eta = 0.25\), and with \(\eta = 1\)?

With \(\eta = 0.25\) the update is \(w \leftarrow w - 0.5(w - 3)\), so \(w\) goes \(1 \to 2 \to 2.5 \to 2.75 \to \dots\). Each step halves the distance to 3 and the weight converges. With \(\eta = 1\) the update is \(w \leftarrow w - 2(w - 3) = 6 - w\), so \(w\) goes \(1 \to 5 \to 1 \to 5 \to \dots\). It bounces for ever and never reaches the minimum, which is Krish's warning about a large learning rate. Any \(\eta > 1\) on this curve throws the weight further away with every step.

Q6Why does a network need an activation function at all?

Without one, each neuron computes \(\mathbf{w}^\top\mathbf{x} + b\), which is linear regression. Stacking such layers does not help, because \(W_2(W_1\mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2\) equals \((W_2W_1)\mathbf{x} + (W_2\mathbf{b}_1 + \mathbf{b}_2)\), which is still linear. The activation function gives the network non-linear properties, so it can solve non-linear problems. The sigmoid also squeezes the output into the range 0 to 1, which the 0.5 threshold turns into a class.

Q7List Krish's five training steps and say which belong to forward propagation and which to backward propagation.

(1) The input layer receives a record, (2) the weights are applied, (3) each neuron adds up the weighted inputs and its bias, and (4) an activation function is applied. Steps 2 to 4 repeat layer by layer up to the output, and steps 1 to 4 are forward propagation. (5) The loss between \(y\) and \(\hat y\) is computed, and an optimizer updates the weights to minimize it. That is backward propagation. The two passes repeat many times until the network is trained.

Q8How many weights and biases does the multi-layer network in the figure have (4 inputs, hidden layers of 5 and 4 neurons, 3 outputs)?

Weights: \(4 \cdot 5 + 5 \cdot 4 + 4 \cdot 3 = 20 + 20 + 12 = 52\), one per connection. Biases: one per hidden and output neuron, \(5 + 4 + 3 = 12\). That makes 64 parameters, and every backward pass updates each of them with \(w_{\text{new}} = w_{\text{old}} - \eta\,\partial L/\partial w_{\text{old}}\).
