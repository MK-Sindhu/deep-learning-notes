Encoder–decoder models and attention

One recipe covers captioning, translation, question answering and more: an encoder network turns the input into vectors, and a decoder generates the output from them. Attention then lets the decoder choose, at every step, which parts of a sentence, an image or a document to read.

At a glance

  • An RNN language model computes the next-word distribution as \(\operatorname{softmax}(V\mathbf{s}_t + \mathbf{c})\). The state \(\mathbf{s}_t\) stands in for all previous words.
  • An encoder–decoder model adds an encoder (CNN for images, RNN for text, RNN of CNNs for video) whose output conditions the decoder, either as its initial state \(\mathbf{s}_0\) or as an extra input at every step.
  • Every application is described by the same list: data, encoder, decoder, parameters, loss (usually a sum of cross-entropies) and algorithm (gradient descent with backpropagation).
  • Attention replaces the single encoding with a fresh context vector at each decoder step, \(\mathbf{c}_t = \sum_j \alpha_{jt}\mathbf{h}_j\). The weights \(\alpha_{jt}\) are a softmax over \(j\) of scores \(e_{jt} = \mathbf{v}^\top\tanh(U\mathbf{s}_{t-1} + W\mathbf{h}_j)\). No one labels the true weights; they are learned end to end, and heat maps show they align sensibly.
  • For images, attend over the 196 locations of a 14 × 14 × 512 convolutional feature map. For dialogs and documents (sequences of sequences), use a hierarchical encoder, with attention over words and then over sentences.

Language modelling with an RNN, revisited

So far the course has built three kinds of networks (feedforward, convolutional and recurrent) and used each on its own. This lecture combines them. It starts from a problem seen before, language modelling: given the first \(t-1\) words (or characters) of a sentence, predict the \(t\)-th one. Autocomplete is the everyday example.

\[ y^* = \arg\max_{j \in \mathcal{V}} \; P(y_t = j \mid y_1, y_2, \dots, y_{t-1}), \qquad \text{shorthand: } P(y_t \mid y_1^{t-1}) \]

\(\mathcal{V}\) is the vocabulary, say 10,000 to 20,000 English words. At every step the network outputs a probability distribution over all of \(\mathcal{V}\), we pick the most probable word, and we continue until the end of the sentence. An RNN computes this distribution from its state:

\[ P(y_t = j \mid y_1^{t-1}) = P(y_t = j \mid \mathbf{s}_t) = \operatorname{softmax}(V\mathbf{s}_t + \mathbf{c})_j \]

Read it from the inside out. \(V\mathbf{s}_t + \mathbf{c}\) is a linear transformation of the state plus a bias, a vector with one entry per vocabulary word. The softmax turns it into a probability distribution, and its \(j\)-th entry is the probability of the \(j\)-th word. The state replaces the whole history \(y_1, \dots, y_{t-1}\) in the condition. That is fair: each step receives only one word as input, but the recurrent connections carry everything seen so far into \(\mathbf{s}_t\).

The five ingredients M1 · 4:19

DataAll sentences from a large corpus, say Wikipedia.
Model\(\mathbf{s}_t = \sigma(W\mathbf{s}_{t-1} + U\mathbf{x}_t + \mathbf{b})\), \(\;P(y_t = j \mid y_1^{t-1}) = \operatorname{softmax}(V\mathbf{s}_t + \mathbf{c})_j\)
Parameters\(U, V, W, \mathbf{b}, \mathbf{c}\)
Loss\(\mathscr{L}(\theta) = \sum_{t=1}^{T} \mathscr{L}_t(\theta)\), \(\;\mathscr{L}_t(\theta) = -\log P(y_t = \ell_t \mid y_1^{t-1})\), where \(\ell_t\) is the true word at step \(t\): a sum of cross-entropies
AlgorithmBackpropagation through time (Lecture 11)

The output at each step is a composite function of the inputs, so the model is trainable end to end: gradients flow from the loss back to every parameter. Vanishing and exploding gradients are dealt with by replacing the RNN with an LSTM (Lecture 12).

M1 · 7:32 M1 · 9:44 the initial state

What the network reads at each step

When generating, the input \(\mathbf{x}_t\) is simply the word predicted at the previous step. If word \(j\) received the highest probability at step \(t-1\), then

\[ \mathbf{x}_t = \mathbf{e}(v_j), \]

the one-hot vector of the \(j\)-th vocabulary word. Generation starts from a special \(\langle\text{GO}\rangle\) symbol and ends when the network outputs \(\langle\text{stop}\rangle\); both are added to the vocabulary as extra words. During training the true sentence is known, so the true previous word is used as the input. (Standard name, not used in the lecture: teacher forcing.)

One-hot is only one possible representation of a word 9:13. In practice the input is a pre-trained embedding of the \(j\)-th word, for example its word2vec vector from Lecture 10.

The initial state \(\mathbf{s}_0\) is not computed from anything. Nobody can say what the state "before the first word" should mean, so it is initialized randomly and learned along with the other parameters of the RNN (or LSTM, or GRU). The lecture promises to come back to it; image captioning will give it a meaning.

Generating a sentence from an image

A language model generates a sentence given the previous words. Image captioning generates it given the previous words and an image \(I\): for a photo, "A man throwing a frisbee in a park", one word at a time. The quantity of interest becomes \(P(y_t \mid y_1^{t-1}, I)\), which is again a conditional distribution with one more thing to condition on.

Earlier the history \(y_1^{t-1}\) was replaced by the vector \(\mathbf{s}_t\). The image can be replaced by a vector too. Every layer of a CNN learns an abstract representation of the image, and we trust such a representation to contain the image's information, just as \(\mathbf{s}_t\) contains the history. By convention the representation is taken from fc7, the fully connected layer just before the output layer of a network like VGG-16 (Lecture 8); it is numbered 7 because the five convolutional blocks are counted first. So we model

\[ P(y_t = j \mid y_1^{t-1}, I) \quad \text{as} \quad P(y_t = j \mid \mathbf{s}_t, \text{fc7}(I)). \]

This is one choice among several. A student suggested a non-neural one in class: detect the objects first (man, frisbee) and condition on their names. Conditioning on \(\text{fc7}(I)\) is the neural way, and there are still two ways to wire it in.

Option 1: the image is the initial state M1 · 16:53

Set \(\mathbf{s}_0 = \text{fc7}(I)\). The mysterious learned \(\mathbf{s}_0\) now has a meaning: the starting point of the description is the image. Then \(\mathbf{s}_1\) depends on \(\mathbf{s}_0\), every later state depends on the one before, and so every \(P(y_t = j)\) depends on \(\text{fc7}(I)\). This computes \(P(y_t = j \mid \mathbf{s}_t, \text{fc7}(I))\). There is one practical detail 17:31. fc7 has 4096 numbers and the state has \(d\), so the image vector is first projected by a learnable \(d \times 4096\) matrix. The first input \(\mathbf{x}_1\) is \(\langle\text{GO}\rangle\).

Option 2: the image at every step M1 · 18:35

Feeding the image only once looks slightly inefficient. The more explicit alternative concatenates it with the input at every step, so each state is computed directly from the image:

\[ \mathbf{s}_t = \text{RNN}\big(\mathbf{s}_{t-1}, [\mathbf{x}_t, \text{fc7}(I)]\big) \]

You could think of other ways of conditioning \(P(y_t = j)\) on fc7.

M1 · 19:05 M1 · 20:14 beyond the diagram

The encoder–decoder architecture

The captioning model has two parts. An encoder, here a CNN, reads the input and encodes it as a representation. A decoder, here an RNN, generates (decodes) the output sentence from that encoding. Both are neural networks. This is the encoder–decoder architecture; such models became extremely popular, and the lecture credits them with much of deep learning's popularity. The encoder's output can go in once, as \(\mathbf{s}_0\), or be fed to every step of the decoder.

The diagram, with one box wired to another, is the easy part. What matters is the function behind it. The output \(y_t\) is the output layer applied to the RNN applied to the CNN applied to \(x\), so you should be able to write \(y\) as a function of \(x\), and the gradient can flow back through every piece.

For any encoder–decoder model, write down the chain of equations from the input \(x\) to the output distribution. If you can, you understand the model.

M2 · 0:12 M2 · 0:44 captioning

Four questions for every application

Module 16.2 runs through a series of tasks and asks the same four questions of each:

  1. What kind of network can encode the input(s)? (What is an appropriate encoder?)
  2. What kind of network can decode the output? (What is an appropriate decoder?)
  3. What are the parameters of the model?
  4. What is an appropriate loss function?

With the data and the training algorithm, these give the full description of a model.

Image captioning, written out

Data\(\{x_i = \text{image}_i,\ y_i = \text{caption}_i\}_{i=1}^N\); each caption is itself a sequence \(y_{i1}, \dots, y_{iT}\).
Encoder\(\mathbf{s}_0 = \text{CNN}(x_i)\). "CNN" stands for whichever representation you take: fc7, conv5, max-pool 5.
Decoder\(\mathbf{s}_t = \text{RNN}(\mathbf{s}_{t-1}, \mathbf{e}(\hat y_{t-1}))\), \(\;P(y_t \mid y_1^{t-1}, I) = \operatorname{softmax}(V\mathbf{s}_t + \mathbf{b})\). \(\mathbf{e}(\hat y_{t-1})\) is the embedding (one-hot or word2vec) of the word predicted at the previous step.
Parameters\(U_{\text{dec}}, V, W_{\text{dec}}, W_{\text{conv}}, \mathbf{b}\): the CNN's filters, the RNN's weights and the output layer.
Loss\(\mathscr{L}(\theta) = \sum_{t=1}^{T} \mathscr{L}_t(\theta) = -\sum_{t=1}^{T} \log P(y_t = \ell_t \mid y_1^{t-1}, I)\)
AlgorithmGradient descent with backpropagation: through time in the decoder, and on into the CNN.

The slides write the outer sum with index \(i\); it runs over the time steps \(t\) of one caption. The total training loss adds this over the \(N\) training pairs.

The final \(y\) is a composite function of the image: many computations sit in between, but there is a path from \(x\) to \(y\), so the whole model is one network.

Sequence in, sequence out: entailment, translation, transliteration

Textual entailment: given a premise, generate a hypothesis that follows from it. The premise "It is raining outside" entails "The ground is wet". The data is \(\{x_i = \text{premise}_i,\ y_i = \text{hypothesis}_i\}_{i=1}^N\). Both input and output are word sequences, so the encoder and decoder are both RNNs (replace them with LSTMs if you like). The model becomes one network by handing the encoder's last state to the decoder.

\[ \begin{aligned} &\text{Encoder:} && \mathbf{h}_t = \text{RNN}(\mathbf{h}_{t-1}, \mathbf{x}_{it}) \\ &\text{Decoder (option 1):} && \mathbf{s}_0 = \mathbf{h}_T \;\; (T = \text{length of the input}), \quad \mathbf{s}_t = \text{RNN}(\mathbf{s}_{t-1}, \mathbf{e}(\hat y_{t-1})) \\ &&& P(y_t \mid y_1^{t-1}, x) = \operatorname{softmax}(V\mathbf{s}_t + \mathbf{b}) \end{aligned} \]

Parameters \(U_{\text{dec}}, V, W_{\text{dec}}, U_{\text{enc}}, W_{\text{enc}}, \mathbf{b}\). The loss is the sum of cross-entropies \(-\sum_t \log P(y_t = \ell_t \mid y_1^{t-1}, x)\), and training is gradient descent with backpropagation, through the decoder, across the hand-off \(\mathbf{s}_0 = \mathbf{h}_T\) and all the way back through the encoder.

Option 2 6:32 feeds the encoding at every step. An RNN takes exactly two inputs, the previous state and the current input, so \(\mathbf{h}_T\) is concatenated with the word embedding:

\[ \mathbf{s}_t = \text{RNN}\big(\mathbf{s}_{t-1}, [\mathbf{h}_T, \mathbf{e}(\hat y_{t-1})]\big) \]

Parameters, loss and training algorithm stay the same. From here on the lecture states only option 1, since option 2 is the same small change each time.

Machine translation: the English sentence "I am going home" becomes the Hindi "Mein ghar ja raha hoon". The data is \(\{x_i = \text{source}_i,\ y_i = \text{target}_i\}_{i=1}^N\), and the model, parameters, loss and algorithm are exactly the entailment ones, with the same two options.

Transliteration: write a word in another script. It is typically used for names: translating "Thomas" into Hindi means writing "Thomas" in Devanagari. The slides' example takes the characters I-N-D-I-A to इंडिया. Input and output are sequences of characters, so again an RNN encoder and an RNN decoder with the same equations. (The option 2 slide writes the concatenation as \([\mathbf{e}(\hat y_{t-1}), \mathbf{h}_T]\); the order does not matter.)

M2 · 9:26

Two inputs, one answer: image question answering

Given an image and a question about it ("What is the bird's color?"), produce the answer ("White"). To keep it simple the answer is a single word from a fixed vocabulary, so the output is a single probability distribution over the possible answers.

The recipe is to encode each input with the network that suits it, concatenate the encodings, and pass the result to a feed-forward layer that predicts the distribution.

\[ \hat{\mathbf{h}}_I = \text{CNN}(I), \qquad \tilde{\mathbf{h}}_t = \text{RNN}(\tilde{\mathbf{h}}_{t-1}, \mathbf{q}_{it}), \qquad \mathbf{s} = [\tilde{\mathbf{h}}_T;\ \hat{\mathbf{h}}_I], \qquad P(y \mid q, I) = \operatorname{softmax}(V\mathbf{s} + \mathbf{b}) \]

The data is \(\{x_i = \{I, q\}_i,\ y_i = \text{answer}_i\}_{i=1}^N\). The parameters are \(V, \mathbf{b}\) of the output layer, \(U_q, W_q\) of the question RNN and \(W_{\text{conv}}\) of the CNN (the slide lists \(\mathbf{b}\) twice). The loss is a single cross-entropy, \(\mathscr{L}(\theta) = -\log P(y = \ell \mid I, q)\), and gradient descent with backpropagation trains it, back through the question RNN and back into the CNN.

M2 · 11:47 M2 · 12:19 video M2 · 13:27 classification, dialog

Summaries, videos and dialog

  • Document summarization. "India beats Srilanka to win ICC WC 2011. Dhoni and Gambhir's half centuries help beat SL" becomes "India won the world cup". An RNN encoder reads the document word by word, \(\mathbf{s}_0 = \mathbf{h}_T\), and an RNN decoder writes the summary. Parameters, loss and algorithm are those of translation.
  • Video captioning. A video is a sequence of frames, and each frame is an image. So encode every frame with a CNN and run an RNN over the frame encodings, \(\mathbf{h}_t = \text{RNN}(\mathbf{h}_{t-1}, \text{CNN}(x_{it}))\). In class this always gets called an RNN of CNNs. Then \(\mathbf{s}_0 = \mathbf{h}_T\) and an RNN decoder writes "A man walking on a rope". Parameters \(U_{\text{dec}}, W_{\text{dec}}, V, \mathbf{b}, W_{\text{conv}}, U_{\text{enc}}, W_{\text{enc}}\); the loss is the sum of cross-entropies, and backpropagation goes through time and through the CNNs.
  • Video classification. The same RNN-of-CNNs encoder, but the output is one activity label ("Surya Namaskar"), so the decoder is a feed-forward softmax: \(\mathbf{s} = \mathbf{h}_T\), \(P(y \mid \text{video}) = \operatorname{softmax}(V\mathbf{s} + \mathbf{b})\), with loss \(-\log P(y = \ell \mid \text{video})\). Parameters \(V, \mathbf{b}, W_{\text{conv}}, U_{\text{enc}}, W_{\text{enc}}\).
  • Dialog. The utterance "How are you" gets the response "I am fine". RNN encoder, \(\mathbf{s}_0 = \mathbf{h}_T\), RNN decoder, as in translation.

Why has this framework become so popular 14:00? The tasks above span different modalities (images, videos, sentences and combinations of them), and every one is modelled by a single end-to-end network built only from neural components: convolutional, recurrent and feed-forward layers. The lecture stretches it further to video question answering: an RNN for the question, an RNN of CNNs for the video, concatenate the two, and a feed-forward network predicts an answer from a fixed vocabulary. How well each model works is a separate question. Before this framework, many of them could not be written as one end-to-end network at all.

The module ends with a challenge 15:33. Pick a machine learning problem from your own field and model it in the encoder–decoder framework. The example from class: treat a person's DNA as a sequence of genes, encode it with an RNN, and predict a probability distribution over diseases the person may be susceptible to.

M3 · 0:42 M3 · 1:43 how people translate

Why the plain encoder–decoder falls short

The lecture motivates attention with translation, now from Hindi to English: "Main ghar ja raha hoon" becomes "I am going home". In every model so far, the encoder reads the sentence once and encodes it. At each step the decoder then uses that same encoding to produce a new word, whether it was given once as \(\mathbf{s}_0\) or at every step. All the models of Module 16.2 are incomplete in this sense.

People do not translate like this. Reading a sentence once and holding all of it in mind while writing the translation invites forgetting, especially for a typical 25-word Wikipedia sentence. And most input words are irrelevant to any particular output word. A person produces each output word by focusing on only a few input words. At each step there is a distribution over the input words that says how much attention each one gets:

Output stepWord producedMaingharjarahahoon
\(t = 1\)I10000
\(t = 2\)am00001
\(t = 3\)going000.50.50
\(t = 4\)home01000

To write "I" it does not matter that you have forgotten the translation of "ghar", as long as you know "Main". "going" draws on both "ja" and "raha"; every other output word comes from one input word. Ideally the decoder would be fed only this relevant information, the encodings of the relevant words, at each step. The vanilla model makes every step look at the entire sentence, and that is the conceptual error to correct.

M3 · 3:22 M3 · 4:31 a weighted sum

If an oracle gave us the weights

Suppose an oracle told us which input words matter at decoder step \(t\), and assume the encoder has already run, giving one vector \(\mathbf{h}_j\) per input word. If one word matters, feed its vector to the decoder and nothing else. If two matter, we could concatenate their vectors, but at another step four words might matter, and the input size would keep changing. A weighted average solves this: whatever the weights, it has the same dimension as each \(\mathbf{h}_j\).

\[ \mathbf{c}_t = \sum_{j=1}^{T} \alpha_{jt}\,\mathbf{h}_j, \qquad \alpha_{jt} \ge 0, \quad \sum_{j=1}^{T}\alpha_{jt} = 1 \]

At step 3 the oracle's weights are 0.5 on "ja" and 0.5 on "raha", so \(\mathbf{c}_3 = 0.5\,\mathbf{h}_3 + 0.5\,\mathbf{h}_4\). In general we take a weighted combination of all the encoder vectors, with weights from the oracle. Intuitively this should work better than the vanilla model, which overloads the decoder with the whole sentence at every step. Now the decoder gets only the information it needs to produce the current word.

M3 · 6:13 M3 · 9:40 softmax M3 · 10:47 the form of f_ATT

Learning the weights: scores, softmax and \(f_{\text{ATT}}\)

In practice there is no oracle, so the machine has to learn the weights from data, and learning means introducing parameters. First define a score \(e_{jt}\) for how important the \(j\)-th input word is for decoding the \(t\)-th output word. Two things should affect it 6:46:

  • The input word itself, represented by its encoder state \(\mathbf{h}_j\). This is a contextual representation: the encoder RNN computed it knowing the neighbouring words.
  • What the decoder has done so far, summarized by its state \(\mathbf{s}_{t-1}\). Once the decoder has produced "home" it has no reason to look at "ghar" again.
\[ e_{jt} = f_{\text{ATT}}(\mathbf{s}_{t-1}, \mathbf{h}_j) \]

The scores can be any real numbers, but we want weights that form a distribution over the input words. A softmax over \(j\) does this:

\[ \alpha_{jt} = \frac{\exp(e_{jt})}{\sum_{j'=1}^{T} \exp(e_{j't})} \]

\(\alpha_{jt}\) is the probability of focusing on the \(j\)-th input word to produce the \(t\)-th output word. We now learn the \(\alpha\)s instead of being told them, and that needs a parametric form for \(f_{\text{ATT}}\). One choice among many:

\[ e_{jt} = \mathbf{v}_{\text{att}}^\top \tanh\big(U_{\text{att}}\,\mathbf{s}_{t-1} + W_{\text{att}}\,\mathbf{h}_j\big) \]

Check the shapes. \(U_{\text{att}}\mathbf{s}_{t-1}\) and \(W_{\text{att}}\mathbf{h}_j\) are added, so both matrices must map to the same size, say \(d_1\): \(U_{\text{att}}, W_{\text{att}} \in \mathbb{R}^{d_1 \times d}\). The tanh then gives a vector in \(\mathbb{R}^{d_1}\). But \(e_{jt}\) is a scalar (it has two indices, yet it is one number: the importance of input \(j\) at step \(t\)), so \(\mathbf{v}_{\text{att}} \in \mathbb{R}^{d_1}\) turns the vector into a number by a dot product. That is the job of the three parameters: let the score depend on \(\mathbf{s}_{t-1}\) and \(\mathbf{h}_j\), and make the output a scalar. The slides take \(d_1 = d\): \(\mathbf{v}_{\text{att}} \in \mathbb{R}^d\), \(U_{\text{att}}, W_{\text{att}} \in \mathbb{R}^{d \times d}\). They are learned with the other parameters of the encoder and decoder.

Attention at decoder step t \[ e_{jt} = \mathbf{v}_{\text{att}}^\top \tanh\big(U_{\text{att}}\mathbf{s}_{t-1} + W_{\text{att}}\mathbf{h}_j\big), \qquad \alpha_{jt} = \frac{\exp(e_{jt})}{\sum_{j'} \exp(e_{j't})}, \qquad \mathbf{c}_t = \sum_{j=1}^{T}\alpha_{jt}\,\mathbf{h}_j \]

The scoring function is a small feed-forward network: a linear map, a tanh, and a second linear map to a scalar. (Standard name, not used in the lecture: additive or Bahdanau attention.)

Notation. One slide writes the encoder states as \(\mathbf{c}_j\); the lecture then fixes \(\mathbf{s}_t\) for decoder states and \(\mathbf{h}_j\) for encoder states, which these notes use throughout, with \(\mathbf{c}_t\) for the context vector. The slides write \(\mathbf{v}_{\text{att}}\) as \(V_{att}\), and call the number of input words \(M\) in one place and \(T\) in another.

M3 · 12:29 M3 · 14:44 the bicycle

Learning attention without being told where to look

The model would make complete sense if the true weights were given at training time. Say that at the step producing "going" the true weights are \(\boldsymbol{\alpha}^{\text{true}} = [0, 0, 0.5, 0.5, 0]\) and the model predicts \(\boldsymbol{\alpha}^{\text{pred}} = [0.1, 0.1, 0.35, 0.35, 0.1]\). We could add a loss \(\mathscr{L}(\boldsymbol{\alpha}^{\text{true}}, \boldsymbol{\alpha}^{\text{pred}})\), squared error for example, to the usual \(\mathscr{L}(\theta)\) and minimize both. Then \(U_{\text{att}}, W_{\text{att}}, \mathbf{v}_{\text{att}}\) would be tuned to bring the predicted weights close to the true ones.

In practice \(\boldsymbol{\alpha}^{\text{true}}\) is very hard to get 14:07. Someone would have to annotate, for every target word of every training sentence, which source words it came from, and nobody can collect that much annotated data. The data stays pairs of source and target sentences. So why should the model work without this supervision?

Because it is a better modelling choice. The lecture explains this with an analogy. Suppose you decide to learn to ride a bicycle without holding the handlebar. It is conceivable that after years of trying you manage it. Now someone suggests you hold the handlebar. That suggestion gives no supervision about how much force to put on the left or right hand; you still find that out yourself by falling to one side and then the other. But the second model, with hands on the handlebar, has extra controls to adjust and is closer to how people actually learn, so you learn better. Attention plays the role of the handlebar. The model is told only that it may focus on different words at different steps; which words, it must discover.

The attention parameters are trained like all the others. If the output at some step is wrong, the cause may be \(V\), the recurrent weights or poor attention weights, and backpropagation adjusts all of them. People learning to translate are not given word-by-word alignments either; they see many translations and work out what to focus on. With enough data the model should learn the attention weights the same way. In the lecture's words, that is the hope, "and hope is a good thing". In practice attention models do work better than vanilla encoder–decoder models.

M3 · 18:33 M3 · 20:08 the decoder step M3 · 23:05 a generic framework

Encode, attend, decode: the full translation model

Now put attention into the translation model and answer the same questions again. The data does not change: source and target sentences, with no information about which words to attend to.

\[ \begin{aligned} &\text{Data:} && \{x_i = \text{source}_i,\ y_i = \text{target}_i\}_{i=1}^N \\ &\text{Encoder:} && \mathbf{h}_t = \text{RNN}(\mathbf{h}_{t-1}, \mathbf{x}_t), \qquad \mathbf{s}_0 = \mathbf{h}_T \\ &\text{Decoder:} && e_{jt} = \mathbf{v}_{\text{attn}}^\top \tanh(U_{\text{attn}}\mathbf{h}_j + W_{\text{attn}}\mathbf{s}_{t-1}) \\ &&& \alpha_{jt} = \operatorname{softmax}_j(e_{jt}), \qquad \mathbf{c}_t = \sum_{j=1}^{T}\alpha_{jt}\,\mathbf{h}_j \\ &&& \mathbf{s}_t = \text{RNN}\big(\mathbf{s}_{t-1}, [\mathbf{e}(\hat y_{t-1}), \mathbf{c}_t]\big) \\ &&& P(y_t \mid y_1^{t-1}, x) = \operatorname{softmax}(V\mathbf{s}_t + \mathbf{b}) \end{aligned} \]

Parameters: \(U_{\text{dec}}, V, W_{\text{dec}}, U_{\text{enc}}, W_{\text{enc}}, \mathbf{b}\), plus the attention parameters \(U_{\text{attn}}, W_{\text{attn}}, \mathbf{v}_{\text{attn}}\). The loss (sum of cross-entropies) and the algorithm (gradient descent with backpropagation) remain the same.

  1. One decoder step with attention
  2. Score every input word against the decoder's state so far: \(e_{jt}\) from \(\mathbf{h}_j\) and \(\mathbf{s}_{t-1}\), for \(j = 1, \dots, T\).
  3. Turn the scores into attention weights: \(\alpha_{jt} = \operatorname{softmax}_j(e_{jt})\).
  4. Take the weighted combination of the encoder states: \(\mathbf{c}_t = \sum_j \alpha_{jt}\mathbf{h}_j\).
  5. Update the decoder with the previous word and the context: \(\mathbf{s}_t = \text{RNN}(\mathbf{s}_{t-1}, [\mathbf{e}(\hat y_{t-1}), \mathbf{c}_t])\).
  6. Output the distribution \(\operatorname{softmax}(V\mathbf{s}_t + \mathbf{b})\); when generating, its most probable word becomes \(\hat y_t\), the next step's input.

The summary slide writes \(W_{\text{attn}}\mathbf{s}_t\) inside the score and swaps the letters (\(U\) now multiplies \(\mathbf{h}_j\)). The letters are just names. The state must be \(\mathbf{s}_{t-1}\), as on the earlier slide and in the video, because \(\mathbf{s}_t\) is computed from \(\mathbf{c}_t\), which needs the scores. The slide's parameter list also leaves out \(W_{\text{attn}}\).

The attention network is a simple feed-forward network, and only these three equations need to be fitted into a model. Like the encoder–decoder framework, this encode–attend–decode framework is generic. Try going back to each application of Module 16.2 and adding attention, answering the same questions (data, encoder, decoder, loss, training algorithm). The data never changes: nobody supplies the \(\alpha\)s. Lecture 14 takes the idea further: transformers drop the recurrence and build the encoder and decoder from attention alone.

M3 · 24:12 M3 · 24:47 heat maps M3 · 26:22 translation

Does attention learn something meaningful?

Does the model really learn to focus on the most relevant input words at each step? To find out, plot the weights. With \(L\) output steps and \(T\) input words, the weights form an \(L \times T\) matrix. Drawn as a heat map, each cell shows \(\alpha_{tj}\), the importance the model gave the \(j\)-th input word when predicting the \(t\)-th output word; the darker the cell, the more attention. The picture is a soft alignment between input and output. Many papers include such a plot, and it is worth making one whenever you use attention, to check that the weights are meaningful.

  • Summarization (Rush et al. 2015). When the summary says "terrorism", the most attended input word is "terrorism"; "Russia" attends mostly to "Russian", "calls" to "called" and "front" to "front". It does not always work this cleanly, but meaningful patterns appear.
  • Translation between English and French (Cho et al. 2015). Word order in the two languages largely agrees, so translation is roughly monotonic: the \(k\)-th output word attends to about the \(k\)-th input word, and most of the weight lies on the diagonal.
  • Video captioning (Yao et al. 2015). The same kind of plot, with attention over the video's frames as each word is generated.

Attention over images

The module videos stop at the heat maps; this section and the next two follow the slides (Modules 16.4 and 16.5). How should attention work for image captioning? For text, the encoder gives a representation for every location (time step) of the input, and attention chooses among them. For images we have been using the fc7 vector, a single representation that holds no location information. So there is nothing to choose among.

The fix is to take the output of a convolutional layer instead, since convolutional layers keep spatial information. In VGGNet (Lecture 8) the output of the fifth convolutional block is a \(14 \times 14 \times 512\) feature map. Treat it as 196 locations, each with a 512-dimensional representation. The model then learns an attention over these locations, and each location corresponds to an actual region of the image.

Written out in the notation of the text case (the slide shows this as a figure), with \(\mathbf{a}_j\) the vector at location \(j\):

\[ e_{jt} = f_{\text{ATT}}(\mathbf{s}_{t-1}, \mathbf{a}_j), \qquad \alpha_{jt} = \frac{\exp(e_{jt})}{\sum_{j'=1}^{196}\exp(e_{j't})}, \qquad \mathbf{c}_t = \sum_{j=1}^{196}\alpha_{jt}\,\mathbf{a}_j \in \mathbb{R}^{512} \]

The slides' examples (from Cho et al. 2015) show captions with one word underlined and the attended part of the image in white. The model attends to the correct object when it names it.

Slides

Sequences of sequences: hierarchical encoders

Consider a dialog between a user (U) and a bot (B):

ContextU: Can you suggest a good movie?
B: Yes, sure. How about Logan?
U: Okay, who is the lead actor?
ResponseB: Hugh Jackman, of course

The dialog is a sequence of utterances, and each utterance is a sequence of words. The input is a "sequence of sequences". A natural encoder is a two-level hierarchical RNN encoder. The first-level RNN runs over the words of each utterance and gives one representation per utterance. A second RNN runs over this sequence of utterance representations and gives a single representation for the whole context. The decoder generates the response conditioned on it.

Documents have the same shape: a document is a sequence of sentences, and each sentence a sequence of words. Take document classification (or summarization). The slides' example document, which starts "Politics is the process of making decisions…", should be classified as Politics. A hierarchical RNN models it:

\[ \begin{aligned} &\text{Data:} && \{\text{document}_i, \text{class}_i\}_{i=1}^N \\ &\text{Word-level (1) encoder:} && \mathbf{h}^1_{ij} = \text{RNN}(\mathbf{h}^1_{i,j-1}, \mathbf{w}_{ij}), \qquad \mathbf{s}_i = \mathbf{h}^1_{iT_i} \\ &\text{Sentence-level (2) encoder:} && \mathbf{h}^2_i = \text{RNN}(\mathbf{h}^2_{i-1}, \mathbf{s}_i), \qquad \mathbf{s} = \mathbf{h}^2_K \\ &\text{Decoder:} && P(y \mid \text{document}) = \operatorname{softmax}(V\mathbf{s} + \mathbf{b}) \end{aligned} \]

Parameters \(W^1_{\text{enc}}, U^1_{\text{enc}}, W^2_{\text{enc}}, U^2_{\text{enc}}, V, \mathbf{b}\); loss cross-entropy; algorithm gradient descent with backpropagation. Here \(\mathbf{w}_{ij}\) is the \(j\)-th word of sentence \(i\), \(T_i\) is the length of sentence \(i\) and \(K\) the number of sentences. Each sentence is summarized by its last word-level state, and the document by the last sentence-level state.

Slides

Hierarchical attention

To add attention to a hierarchical model we need it at two levels: first attend to the important (most informative) words in each sentence, then to the important sentences in the document. The slides use the Hierarchical Attention Network of Yang et al.

\[ \begin{aligned} &\text{Word level (1):} && \mathbf{h}_{ij} = \text{RNN}(\mathbf{h}_{i,j-1}, \mathbf{w}_{ij}), && \mathbf{u}_{ij} = \tanh(W_w\mathbf{h}_{ij} + \mathbf{b}_w), \\ &&& \alpha_{ij} = \frac{\exp(\mathbf{u}_{ij}^\top\mathbf{u}_w)}{\sum_{t}\exp(\mathbf{u}_{it}^\top\mathbf{u}_w)}, && \mathbf{s}_i = \sum_j \alpha_{ij}\,\mathbf{h}_{ij} \\ &\text{Sentence level (2):} && \mathbf{h}_i = \text{RNN}(\mathbf{h}_{i-1}, \mathbf{s}_i), && \mathbf{u}_i = \tanh(W_s\mathbf{h}_i + \mathbf{b}_s), \\ &&& \alpha_i = \frac{\exp(\mathbf{u}_i^\top\mathbf{u}_s)}{\sum_{i'}\exp(\mathbf{u}_{i'}^\top\mathbf{u}_s)}, && \mathbf{s} = \sum_i \alpha_i\,\mathbf{h}_i \\ &\text{Decoder:} && P(y \mid \text{document}) = \operatorname{softmax}(V\mathbf{s} + \mathbf{b}) \end{aligned} \]

Parameters \(W_w, W_s, V, \mathbf{b}_w, \mathbf{b}_s, \mathbf{b}, \mathbf{u}_w, \mathbf{u}_s\), plus the weights of the two RNNs. The loss is cross-entropy and the algorithm gradient descent with backpropagation.

Compare with translation. There is no decoder state to score against, because the output is a single class. Instead each state goes through a one-layer network, \(\mathbf{u}_{ij} = \tanh(W_w\mathbf{h}_{ij} + \mathbf{b}_w)\), and is scored by its dot product with a learned vector \(\mathbf{u}_w\) (\(\mathbf{u}_s\) at the sentence level). The attention-weighted sums take the place of "use the last state" (\(\mathbf{s}_i = \mathbf{h}^1_{iT_i}\), \(\mathbf{s} = \mathbf{h}^2_K\)) in the plain hierarchical encoder.

Not in the lecture: Yang et al. call \(\mathbf{u}_w\) and \(\mathbf{u}_s\) the word-level and sentence-level context vectors, and their encoders are bidirectional GRUs, which is why the slide's figure shows forward and backward states.

Key terms

Language model
A model of \(P(y_t \mid y_1^{t-1})\); an RNN computes it as \(\operatorname{softmax}(V\mathbf{s}_t + \mathbf{c})\).
Encoder
The network that reads the input and encodes it: a CNN for images, an RNN for sequences, an RNN of CNNs for videos.
Decoder
The network that produces the output from the encoding: an RNN for a sequence, a feed-forward softmax for a single label.
fc7(I)
The 4096-dimensional representation of an image from the fully connected layer fc7 of a CNN such as VGG-16.
Options 1 and 2
Feed the encoding once as \(\mathbf{s}_0\), or concatenate it with the decoder's input at every step.
Textual entailment
Generating a hypothesis that follows from a premise ("It is raining outside" → "The ground is wet").
Transliteration
Writing a word, usually a name, in another script, character by character.
RNN of CNNs
A video encoder: a CNN encodes each frame, an RNN runs over the frame encodings.
Attention weights \(\alpha_{jt}\)
Softmax-normalized importance of input position \(j\) when producing output step \(t\); they sum to 1 over \(j\).
Context vector \(\mathbf{c}_t\)
\(\sum_j \alpha_{jt}\mathbf{h}_j\): the weighted combination of encoder states fed to the decoder at step \(t\).
\(f_{\text{ATT}}\)
The scoring function; here \(\mathbf{v}_{\text{att}}^\top\tanh(U_{\text{att}}\mathbf{s}_{t-1} + W_{\text{att}}\mathbf{h}_j)\), a small feed-forward network.
Soft alignment
The \(L \times T\) heat map of attention weights between output and input words.
Hierarchical attention network
A two-level encoder for sequences of sequences, with attention over words in each sentence and over sentences in the document.

Test yourself

Q1A language model has a 20,000-word vocabulary and a 300-dimensional state. What are the shapes of \(V\), \(\mathbf{c}\) and \(V\mathbf{s}_t + \mathbf{c}\) in \(\operatorname{softmax}(V\mathbf{s}_t + \mathbf{c})\), and what is entry \(j\) of the output?

\(V \in \mathbb{R}^{20000 \times 300}\) (6 million numbers), \(\mathbf{c} \in \mathbb{R}^{20000}\), and \(V\mathbf{s}_t + \mathbf{c} \in \mathbb{R}^{20000}\), one score per word. After the softmax the 20,000 entries are positive and sum to 1; entry \(j\) is \(P(y_t = j \mid y_1^{t-1})\), the probability that the next word is word \(j\).

Q2In captioning option 1 the image enters only as \(\mathbf{s}_0 = \text{fc7}(I)\). Why does the fifth word's distribution still depend on the image, and what extra parameter is needed if \(d = 512\)?

\(\mathbf{s}_5 = \text{RNN}(\mathbf{s}_4, \cdot)\), \(\mathbf{s}_4\) depends on \(\mathbf{s}_3\), and so on back to \(\mathbf{s}_0\); the recurrence carries the image to every step. fc7 has 4096 numbers, so a learnable \(512 \times 4096\) matrix projects it to the state size.

Q3Write the model, parameters and loss for video classification.

Encoder: \(\mathbf{h}_t = \text{RNN}(\mathbf{h}_{t-1}, \text{CNN}(x_{it}))\) over the frames, and \(\mathbf{s} = \mathbf{h}_T\). Decoder: \(P(y \mid \text{video}) = \operatorname{softmax}(V\mathbf{s} + \mathbf{b})\). Parameters \(V, \mathbf{b}, W_{\text{conv}}, U_{\text{enc}}, W_{\text{enc}}\). Loss \(-\log P(y = \ell \mid \text{video})\), trained by gradient descent with backpropagation through time and through the CNN.

Q4If an oracle tells us which input words matter at each step, why take a weighted average of their encoder vectors instead of concatenating them?

The number of relevant words changes from step to step (one, two, four…), so a concatenation would change size and the decoder's input dimension would not be fixed. A weighted average of \(d\)-dimensional vectors is always \(d\)-dimensional.

Q5The scores at the step producing "going" are \(e = [0, 0, 1.25, 1.25, 0]\). Compute the attention weights, and their squared error against \(\boldsymbol{\alpha}^{\text{true}} = [0, 0, 0.5, 0.5, 0]\).

\(e^{1.25} \approx 3.49\), so the denominator is \(3 \times 1 + 2 \times 3.49 = 9.98\) and \(\boldsymbol{\alpha} \approx [0.10, 0.10, 0.35, 0.35, 0.10]\), the slide's \(\boldsymbol{\alpha}^{\text{pred}}\) (exactly, with \(\ln 3.5 \approx 1.2528\)). Squared error: \(3 \times 0.1^2 + 2 \times 0.15^2\) \(= 0.03 + 0.045 = 0.075\).

Q6The decoder state has 512 dimensions, the encoder states 256, and the attention layer \(d_1 = 128\). What are the shapes of \(U_{\text{att}}\), \(W_{\text{att}}\) and \(\mathbf{v}_{\text{att}}\), and how many numbers do they hold?

\(U_{\text{att}} \in \mathbb{R}^{128 \times 512}\) (acting on \(\mathbf{s}_{t-1}\)), \(W_{\text{att}} \in \mathbb{R}^{128 \times 256}\) (acting on \(\mathbf{h}_j\)), \(\mathbf{v}_{\text{att}} \in \mathbb{R}^{128}\), so \(e_{jt}\) is a scalar. Total \(65{,}536 + 32{,}768 + 128 = 98{,}432\).

Q7Nobody provides the true attention weights. How do \(U_{\text{att}}, W_{\text{att}}, \mathbf{v}_{\text{att}}\) get trained, and why should attention help at all?

Through the ordinary translation loss: the output distribution depends on \(\mathbf{c}_t\), which depends on the \(\alpha\)s, so backpropagation sends gradients into the attention parameters whenever a predicted word is wrong. Attention helps because it is a better modelling choice, like holding the handlebar while learning to ride: the model gets controls that let it focus on the relevant words, and it discovers how to use them from data.

Q8For captioning with attention on VGGNet's conv5 output, how many attention weights are computed at each decoder step, how big is \(\mathbf{c}_t\), and why not attend over fc7?

The \(14 \times 14 \times 512\) map gives 196 locations, so 196 weights per step and \(\mathbf{c}_t \in \mathbb{R}^{512}\). fc7 is a single vector with no location information, so there would be nothing to choose among.
